它能做什么

一条消息进来，六个动作自动跑完，中间不需要你碰笔记软件。

📥

原样归档

消息按天写入 Inbox，时间倒序、status:inbox，只增不改。

🔍

内容识别

链接抓正文、截图 OCR、文件解析，完整保留不删减。

🧭

提炼脉络

梳理主题、逻辑结构、前后关系，以及核心观点与论证思路。

⚡

转行动项

把内容落成具体可执行的下一步，无法落地则只归类、不硬造。

📝

生成笔记

按主题归集到 Seed，分类打标签，同主题合并、无则新建。

⏰

定时汇总

每天 20:00 日报、每周日 20:00 周报、每月最后一天月报。

工作流程

从收到消息到沉淀进知识库，共七个阶段。

1

接收并归档原始碎片

原样保存到 📥Inbox，按自然日归档，标 status:inbox。

2

解析内容为全文

链接抓全文、截图 OCR、文件提取，完整保留不删减。

3

提炼脉络与学习点

产出主题 + 逻辑结构 + 前后关系，保留观点、论证、执行步骤。

4

转行动项

能落地就写具体动作；不能落地就只归类，不编造。

5

判定主题归集 Seed

按内容占比定主主题，同主题合并、无则新建，并打标签。

6

定时汇总推送

日报 / 周报 / 月报写入 📑Review，并推送回飞书。

7

沉淀常青与主题地图

符合条件的进 📚Evergreen（人工校验），📝MOC 每月更新。

输入 → 输出

输入

  • 💬 文字消息（飞书私聊）
  • 🔗 公众号 / 网页链接（URL）
  • 🖼️ 截图（图片，OCR 转文字）
  • 📎 文件（附件，解析提取）

输出

  • 📥 Inbox 收件箱：原始碎片（按天）
  • 📝 Seed 种子笔记：提炼笔记
  • 📑 Review：日 / 周 / 月汇总报告
  • 📚 Evergreen / 🗺️ MOC：常青与主题地图

能力边界

清楚知道它做什么、不做什么，比功能本身更重要。

✅ 会做

  • 忠实归档，原文不删减、不臆测
  • 提炼主题、脉络、学习点、行动项
  • 按时生成并推送日报 / 周报 / 月报
  • 分类、打标签、同主题合并

❌ 不做

  • 不替你执行计划、不对外回复
  • 不自动发布到公众号等外部平台
  • 不直接写死 Evergreen 终稿
  • 不删除 / 覆盖 Inbox 原始碎片
  • 不臆测 OCR / 抓取失败的内容

注意事项 / FAQ

这个页面能调用真实 Agent 吗？

不能。本页为纯静态前端，没有任何后端、接口或凭证，所有对话均为脚本回放。

它的输入只能来自飞书吗？

当前设计以飞书私聊为主要入口，支持文字、链接、截图、文件。

什么情况需要人工介入？

OCR / 解析失败且内容重要、主题无法唯一归类、转入常青笔记前校验、主题地图定稿前打磨。
